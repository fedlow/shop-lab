# Симулятор магазина с корзиной покупок

## Цель
Разработать приложение магазина с каталогом, корзиной и сортировкой
товаров четырьмя алгоритмами.

## Структура проекта
- `product.py` — класс `Product`.
- `catalog.py` — каталог товаров.
- `cart.py` — корзина.
- `sorts.py` — 4 алгоритма сортировки + ключи сортировки.
- `discounts.py` — скидки и налоги.
- `ui.py` — текстовое меню.
- `main.py` — точка входа.

## Возможности
- Просмотр каталога товаров с полями: название, категория, цена, вес, описание.
- Добавление и удаление товаров в корзину.
- Отображение содержимого корзины и итогового веса.
- Сортировка корзины:
  - алгоритмы: пузырьковая, вставками, быстрая, слиянием;
  - критерии: цена, вес, категория;
  - направление: по возрастанию или убыванию.
- Подсчёт итоговой стоимости.
- Скидка и налог.
- Текстовый интерфейс с меню.

## Алгоритмы сортировки

| Алгоритм | Сложность (среднее) | Память |
|---|---|---|
| Пузырьковая | O(n²) | O(1) |
| Вставками | O(n²) | O(1) |
| Быстрая | O(n log n) | O(log n) |
| Слиянием | O(n log n) | O(n) |

Все алгоритмы принимают `key` и `reverse`, поэтому одна и та же функция
умеет сортировать по любому полю и в любом направлении.

```
> 1
Каталог:
  Молоко      | Продукты |  89.90 ₽ |  1.00 кг
  Хлеб        | Продукты |  45.00 ₽ |  0.40 кг
  ...
> 2
Название товара: Сыр
«Сыр» добавлен в корзину.
> 5
Алгоритм: 3
Критерий: 1
По возрастанию? (y/n): n
Отсортировано: Быстрая, по цене, по убыванию.

Скидка, %: 10
Налог, %: 20
Сумма без скидок: 410.90 ₽
Со скидкой 10% и налогом 20%: 443.77 ₽
```

## Вывод

В проекте реализованы все требования: каталог, корзина, четыре алгоритма
сортировки, гибкая настройка ключа и направления, подсчёт стоимости,
скидки и налоги. Текстовое меню делает работу интуитивной.
